  - Source

  - SourceItem
  - KnowledgeItem
  - KnowledgeSection

  - Evidence

- Focused tests for idempotency, changed records, evidence and SAT mapping.

## SAT.mdb inspection in current execution environment

The supplied file is recognized as a Microsoft Access database (~11 MB). Binary inspection confirms the presence of expected names including `CONSULTAS`, `HISTORICO`, `DOCUMENTOS`, `IMAGENES`, `ID_CONSULTA`, `ID_HISTORICO`, `CABECERA`, `SINTOMAS`, `SOLUCION` and `OBSERVACIONES`.

This environment did not have an Access reader installed, and outbound package installation was unavailable. Therefore the real tabular extraction is intentionally left as F0.2-B rather than faked.
